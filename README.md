# 🚀 Explore Record (고교 학생부 탐구기록 관리 시스템)

> **학생의 자기주도적 3단계 탐구 설계부터 교사의 나이스(NEIS) 세특 초안 완성 및 엑셀 일괄 관리까지 지원하는 원스톱 웹 애플리케이션입니다.**

---

GitHub Pages 활성화 후 아래 링크로 접속할 수 있습니다:

*(참고: `https://<YOUR-GITHUB-ID>.github.io/explore-record/record.html` 링크로도 학생용 탐구기록지에 접속 가능합니다)*

## ✨ 주요 기능

### 1. 🎓 학생용 탐구기록지 (`student.html` / `record.html`)
- **3단계 탐구 프로세스**:
  - **1단계 (탐구 전략)**: 학생부 작성법 가이드, 7대 심화 작성 전략, 대입 평가 기준 안내
  - **2단계 (주제 기획서)**: 호기심 출발점, 변인 통제(조작·통제·종속), 참고 문헌 및 가설 수립
  - **3단계 (세부 활동지)**: 11개 핵심 질문별 심층 작성, 질문별 추천 세특 1문장 생성 및 자기평가서 완성
- **교육부 기재 금지어 실시간 감지**: 논문, 대회, 외부 수상, 공인어학시험, 유명 기관명 등 70여 개 금지어 실시간 필터링
- **로컬 저장 및 출력**: HTML 결과보고서 다운로드 및 깔끔한 A4 양식 PDF 인쇄 지원

### 2. 🧑‍🏫 교사용 특기사항 생성기 (`teacher.html`)
- **학생 보고서 HTML 일괄 등록**: 파일명 및 보고서 내용 기반 학번·성명·활동구분(자율/진로/팀/교과)·하위집단 자동 분류
- **AI 융합 세특 추천 1문장 엔진**:
  - `Quiz.md` 언어학적 형태소 분석 및 70+ 능동 서술어 탑재
  - 질문 목표 심도와 학생 원문 키워드를 분석하여 3단계 수준 자동 판정:
    - `🌱 기본 탐구` / `🔬 심층 분석` / `🚀 융합 발전`
  - 교사 원클릭 심도 전환 및 실시간 수정 가능한 자동 높이 조절 에디터
- **특기사항 편집기 [접기/펼치기]**: 화면 가림 없이 학생 원문을 넓게 읽으며 초안 작성 가능
- **금지어 위치 원클릭 점프**: 감지된 금지어 뱃지 클릭 시 에디터 내 해당 위치로 자동 스크롤 및 블록 선택
- **엑셀(XLSX) 멀티시트 일괄 내보내기**: 학급·집단별 시트 분할 및 나이스 기재 양식 원클릭 다운로드

## 🔒 개인정보 및 보안 정책
- 본 시스템은 외부 데이터베이스나 유료 AI API 호출 없이 **100% 사용자의 웹 브라우저 로컬에서 안전하게 구동(Client-side)**됩니다.
- 학생의 학번, 성명, 탐구 내용 등 민감한 개인정보는 일체 외부 서버로 전송되지 않습니다.

## 🛠️ GitHub Pages 배포 설정 방법
1. GitHub 저장소(`explore-record`)의 **Settings** 메뉴로 이동합니다.
2. 좌측 메뉴의 **Pages** 탭을 클릭합니다.
3. **Build and deployment** 항목의 **Source**를 `Deploy from a branch`로 선택합니다.
4. **Branch**를 `main` 브랜치 / `/ (root)` 폴더로 설정하고 **Save**를 누릅니다.
5. 1~2분 후 제공되는 URL(`https://<YOUR-GITHUB-ID>.github.io/explore-record/`)로 접속합니다.
